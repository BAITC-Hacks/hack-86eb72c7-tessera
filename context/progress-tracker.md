## Подтверждённые решения

- PostgreSQL и приватное S3 — явный выбор пользователя; конкретные провайдеры не выбраны.
- Clerk, Trigger.dev, Liveblocks, OpenAI — выбранные интеграции, ещё не установлены в package.json.
- **Только русский интерфейс и документация**; технические идентификаторы остаются английскими.
- Детерминированное ядро считает заказ; OpenAI только объясняет, Trigger выполняет, Liveblocks показывает активность. PostgreSQL — единственный источник бизнес-состояния.
- Пользователь проверяет/меняет/утверждает точную редакцию; отправки поставщику в начальной версии нет.
- Проект одного владельца; организации/шаринг/чат/автономные закупки вне начального объёма.
