## Приоритет хакатона

Сначала безопасная основа и синтетический воспроизводимый вертикальный сценарий. Параллельно согласовать данные и импорт реальных материалов. Все M1–M5 обязательны; нельзя заменить математику демонстрацией чата. OpenAI объясняет, Trigger выполняет, Liveblocks отображает; их демонстрация не заменяет проверку исходного кейса.

## Стоп-условия отдельных этапов

- 04: нет решения по ORM/аккаунтам/регионам — не создавать фиктивные подключения.
- 05/07/08: неопределённая семантика реального источника — не превращать пропуски в нули; использовать явно синтетические фикстуры либо diagnostic без утверждения.
- 10/11: нет доступа/согласования передачи — тестировать имитацию/синтетику и честно оставить реальную интеграцию непроверенной.
- 14: нет профиля1С — демонстрационный CSV разрешён с маркировкой, заявление о совместимости запрещено.
