# 14a — Подключение проверки и выгрузки в интерфейсе

## Цель и зависимости

Рабочее место13 показывает реальные результаты; API14 сохраняет проверку и утверждение. Подключить существующие элементы12 без изменения серверных правил. Зависимости: 13, 14.

## Реализация

1. `components/procurement/` и клиентский адаптер13: ввод количества хранится как строка; локальная запятая нормализуется по явному правилу к десятичному контракту, исходная точность не теряется. Изменённая строка требует причины.
2. «Сохранить изменения» отправляет PATCH14 с `reviewVersion`. Пока сохранение не подтверждено, утверждение недоступно. При409 показать «Данные изменились. Обновите результат», не затирать чужую/позднюю версию молча.
3. «Утвердить заказ» открывает явное подтверждение количества позиций/поставщиков и версии. Хеш/версия берутся из серверного review, не собираются из текущей страницы таблицы. Отправить approve14 только после действия пользователя, с защитой двойного клика.
4. После подтверждённого ответа показать автора/время/редакцию. «Скачать CSV» обращается к экспорту с `approvalId`. Обновление страницы читает persisted review/approval; локальный флаг не разблокирует скачивание.
5. Новая правка показывает, что нужно повторное утверждение. Ошибки/сбой скачивания не показывают успешную отправку. Для демоформата постоянно видна оговорка о несогласованной совместимости1С.

## Ограничения

Никаких вызовов утверждения из события Liveblocks/завершения задачи/ответа ИИ. Не добавлять отправку заказа или новые правила закупок. Нельзя переносить изменения на другой запуск автоматически.

## Проверка готовности

- [ ] Браузерный путь: изменить → причина → сохранить → подтвердить → скачать → обновить страницу воспроизводит серверное состояние.
- [ ] Пагинация не исключает строки из утверждения;409 и отказ доступа представлены корректно.
- [ ] Без явного подтверждения нет Approval/экспорта; новый edit отменяет актуальность разрешения на экспорт.
- [ ] Русские подписи, доступный диалог/клавиатура, ошибки загрузки и двойной клик проверены.
- [ ] Тесты, `npm run lint`, `npx tsc --noEmit`, `npm run build` проходят.
