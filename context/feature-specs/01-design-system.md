# 01 — Дизайн-система

Историческая завершённая спецификация. Переведена на русский без изменения функционального объёма. Перед работой читать AGENTS.md.

## Цель и реализация

Установить и настроить shadcn/ui. Добавить Button, Card, Dialog, Input, Tabs, Textarea, ScrollArea. После установки не изменять сгенерированные `components/ui/*` вручную.

Установить lucide-react. Создать `lib/utils.ts` с переиспользуемой `cn()` для объединения классов Tailwind. Компоненты должны соответствовать существующей тёмной теме `globals.css`.

## Проверка готовности

- Все компоненты импортируются без ошибок.
- `cn()` корректно объединяет классы.
- Светлое оформление по умолчанию не появляется.
