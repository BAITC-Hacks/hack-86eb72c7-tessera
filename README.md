# Tessera

Проект хакатона HACKALEM AI: расчёт рекомендуемых заказов для пополнения склада ТОО «Электрокомплект».

Сейчас реализованы UI-примитивы и базовая рамка рабочего пространства. Серверная система и интеграции ещё не реализованы; не путать план с готовым продуктом.

- Исходное задание: `techtask/TECHTASK.md`.
- Инструкции: `AGENTS.md` и шесть документов `context/`.
- План: `context/feature-specs/00-build-plan.md`.
- Исследование файлов: `context/data-inventory.md`.
- Статус и открытые вопросы: `context/progress-tracker.md`.

Выбраны PostgreSQL, приватное S3, Clerk, Trigger.dev, OpenAI и Liveblocks. Интерфейс и документация — на русском. Инструкции настройки сервисов, методология и воспроизводимая демонстрация дополняются при реализации соответствующих этапов.

Для существующего каркаса: `npm ci`, `npm run dev`; проверки — `npm run lint`, `npx tsc --noEmit`, `npm run build`. Сервисы из будущего плана этими командами пока не настраиваются.

Важно: каталог `/context` исключён текущим `.gitignore`; его локальные документы не попадут в обычный коммит без отдельного решения команды. Исходные архивы партнёра считаются конфиденциальными и не предназначены для публичной публикации.
