Прочитай AGENTS.md, шесть контекстных документов, techtask/TECHTASK.md, инвентаризацию данных и план00. Подготовь на русском только следующую согласованную единицу работы.

Укажи существующее состояние, цель, зависимости, конкретные файлы/контракты/статусы, безопасность, ограничения и наблюдаемые критерии. Не меняй завершённые функциональные требования. Проверь зависимости, отсутствие новой несогласованной функциональности, согласованность API с предыдущими этапами и покрытие требования кейса. Не оставляй шаблонных полей в готовом документе. Код и установку пакетов эта инструкция не разрешает.
