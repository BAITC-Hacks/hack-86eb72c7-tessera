# 02 — Базовая рамка редактора

Историческая завершённая спецификация. Перевод не меняет её функциональный объём; русская локализация уже созданных элементов входит в12. Нужны переиспользуемые верхняя панель и оболочка левого сайдбара для последующих экранов.

## Верхняя панель

Создать `components/editor/editor-navbar.tsx`:

- Фиксированная высота, левая/центральная/правая секции.
- Слева кнопка переключения сайдбара.
- Иконки `PanelLeftOpen` / `PanelLeftClose` по состоянию.
- Правая секция пока пустая.
- Тёмный фон и тонкая нижняя граница.

## Сайдбар проектов

Создать `components/editor/project-sidebar.tsx`:

- Плавает поверх рабочей области, открытие не сдвигает содержимое.
- Выдвигается слева; принимает `isOpen` и `onClose`.
- Заголовок «Проекты» и кнопка закрытия (исторический литерал `Projects`).
- shadcn Tabs «Мои проекты» / «Общие» (исторические литералы `My Projects` / `Shared`).
- В обеих вкладках пустое состояние.
- Внизу полноширинная кнопка «Новый проект» с Plus (исторический литерал `New Project`).

## Образец композиции диалога

Использовать существующие токены `globals.css`; предусмотреть заголовок, описание и действия внизу. Конкретные диалоги пока не создавать.

## Проверка готовности

- Новые компоненты компилируются без ошибок TypeScript.
- Нет ошибок линтера.
- Образец композиции диалога готов к будущему использованию.
