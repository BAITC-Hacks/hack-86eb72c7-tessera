# Рамка рабочего пространства

Компоненты задают только переиспользуемую рамку. Экран владеет состоянием панели: передаёт его как `EditorNavbar.isSidebarOpen` и `ProjectSidebar.isOpen`, обработчик переключения как `EditorNavbar.onToggleSidebar`, закрытия — `ProjectSidebar.onClose`. Создание проектов, хранение и конкретные диалоги в завершённый этап02 не входили.

## Композиция будущего диалога

Переиспользовать экспорты `@/components/ui/dialog`; отдельная обёртка или смонтированный диалог пока не нужны. Когда будущая спецификация определит диалог:

- `Dialog` — корень с открывающим элементом и содержимым.
- `DialogTrigger` — управляющий элемент будущей функции.
- `DialogContent` — окно через портал с существующей подложкой/закрытием.
  - `DialogHeader` объединяет `DialogTitle` и `DialogDescription` для доступного заголовка/описания.
  - Предметное содержимое.
  - `DialogFooter` объединяет кнопки из `@/components/ui/button`.

Закрывающее действие: `DialogClose` с `render={<Button variant="outline" />}` — API установленного Base UI, не `asChild`. Альтернатива: `DialogFooter showCloseButton`. Тексты будущего интерфейса — русские; встроенные подписи примитива проверять/локализовать композиционно согласно активной спецификации. Обработчики и интерактивное состояние находятся в клиентском компоненте.

## Существующие токены

Не дублировать цвета: примитивы уже используют `app/globals.css` через `@theme inline`.

| Элемент | Класс | Токен |
| --- | --- | --- |
| Поверхность окна | `bg-popover` | `--popover` |
| Текст и унаследованный заголовок | `text-popover-foreground` | `--popover-foreground` |
| Контур | `ring-foreground/10` | `--foreground`, 10% |
| Описание | `text-muted-foreground` | `--muted-foreground` |
| Нижняя область | `bg-muted/50` | `--muted`, 50% |
| Разделитель | `border-t`, глобальный `border-border` | `--border` |
| Основная кнопка | `bg-primary text-primary-foreground` | `--primary`, `--primary-foreground` |

Подложку предоставляет DialogContent; не создавать вторую. Корневой тёмный класс задаёт значения темы. Это руководство по композиции, не реализованный предметный диалог или действие закупки.
